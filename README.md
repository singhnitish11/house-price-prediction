# 🏠 House Price Prediction Using Machine Learning

## 📌 Project Overview
This project predicts house prices using Machine Learning algorithms based on area, bedrooms, bathrooms, age, location and property type.

## 🎯 Objectives
- Analyze house price data.
- Clean and prepare the dataset.
- Build Machine Learning models.
- Evaluate model performance.
- Identify important features.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 📂 Project Structure

```text
house-price-prediction/
│
├── README.md
├── house_price_prediction.ipynb
├── house_prices.csv
├── model_evaluation_report.md
├── requirements.txt
└── predictions_vs_actual.png
```

## 🤖 Machine Learning Models
1. Linear Regression
2. Decision Tree Regressor
3. Random Forest Regressor

## 📊 Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

## 🚀 How to Run
1. Download or clone this repository.
2. Open Google Colab.
3. Upload the notebook and dataset.
4. Run all notebook cells.
5. Check the model predictions and evaluation results.

## 📈 Results
The models are compared using MAE, MSE and R² Score to identify the best-performing model.
